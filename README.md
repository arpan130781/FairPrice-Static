FairPrice – A Local Market Price Tracker

About the App

FairPrice is a web application built to solve a simple but real problem—lack of transparency in local market pricing. In cities like Mumbai, prices of fruits and vegetables fluctuate daily, and there is no single platform where users can quickly verify if they are paying a fair rate.

The application provides a clean and minimal interface where users can view price listings, search for items, and understand basic trends. What started as a static HTML project has evolved into a more structured and scalable frontend application, with a vision to become a hyperlocal price intelligence platform.

Skills & Commands Used in Development

The development of FairPrice reflects a progression from fundamentals to modern web practices. Initially, the application was built using HTML, CSS, and vanilla JavaScript, focusing on semantic structure, responsive layouts, and DOM manipulation.

As the project evolved, I transitioned to a modern stack using React and Vite. This enabled a component-based architecture, faster builds, and better code organization. I implemented features such as reusable UI components, state management, and client-side routing to improve scalability.

For deployment, I used Vercel, which required building the project and configuring it for production hosting. The key commands and tools used throughout development include:

* npm create vite@latest – to initialize the project
* npm install – to install dependencies
* npm run dev – to run the local development server
* npm run build – to generate the production build (dist folder)
* npm run preview – to test the production build locally

Version control was managed using Git and GitHub, including repository setup, commits, and deployment integration with Vercel.

During development, I also handled multiple real-world issues such as build errors, React import problems, routing issues, and deployment failures. Solving these helped me understand the complete development lifecycle—from writing code to maintaining a live application.

How to Use the App

Using FairPrice is designed to be simple and intuitive. Once the application is opened, users can browse through a list of fruits and vegetables displayed in a clean card-based layout. Each card shows the item name along with its price, making it easy to scan information quickly.

The search functionality allows users to filter items instantly, helping them find specific products without scrolling through the entire list. Navigation between sections such as markets, trends, or reviews (in the current/expanded version) provides a more comprehensive understanding of local pricing.

As the application evolves, additional features like real-time data updates and trend analysis will further enhance usability, making it a practical tool for everyday decision-making.

FairPrice provides a clean and intuitive interface focused on quick price visibility and ease of use. The app includes a location selector showing the active market (e.g., Dadar Vegetable Market, Mumbai) with an option to change it. A search bar enables users to instantly look up items like tomatoes or mangoes without scrolling. Users can toggle between Vegetables and Fruits categories, making navigation simple and organized.

Each item is displayed in a card-based layout showing the product name, unit (per kg/bunch), and a price range visualization (low, average, high) using a colored bar. Additionally, a price indicator tag (e.g., “Fair” or “Average”) helps users quickly understand the value of the current price. The app also shows daily update information along with the number of community submissions, ensuring transparency. Finally, a bottom navigation bar (Home, Markets, Trends, Reviews) allows smooth movement across different sections of the app.
